## 🤖 About

This repository contains my homework solutions for the **Artificial Intelligence** course at **K. N. Toosi University of Technology (KNTU)**.

The assignments combine **theoretical reasoning, mathematical formulation, algorithmic implementation, and practical experimentation** across several core areas of Artificial Intelligence and Machine Learning.

Rather than treating AI methods as black-box tools, the assignments emphasize understanding the **logic, mathematics, and computational process behind the algorithms**.

# 🧪 Implementation Approach

The main philosophy behind the assignments is:

> **Don't just use the algorithm — understand how it works.**

Whenever appropriate, the implementations focus on the internal mechanics of the methods.

For example, instead of viewing a neural network as a single high-level function:

```text
model(x)
```

the underlying process is considered as a sequence of operations:

```text
Input
  ↓
Linear / Convolution
  ↓
Activation
  ↓
Forward Pass
  ↓
Loss
  ↓
Backward Pass
  ↓
Gradients
  ↓
Parameter Update
```

This perspective provides a stronger foundation for understanding modern AI systems.
